# Scientific figures

The saved-data [six PNG/PDF pairs](p1-2026-10-19/) show allocated peak versus the
advance model, directly inspected KV, same-time allocator slack, boundary status
and two signed discrepancy waterfalls. Their historical directory name is retained
for provenance. They are displayed independently in the
[presentation notebook](../../notebooks/FINAL_PRESENTATION.ipynb).

Bands are advance assumptions, not measured confidence intervals. Successful
lengths are not OOM thresholds. Independent peak maxima do not establish
same-time fragmentation.
